## 4. Геометрический расчёт: объём, ЦМ, тензор (фаза 4) — проверка выполнимости

**Метод:** тетраэдральная декомпозиция (Blender 5.0.1 **не имеет** `Mesh.calc_volume`/`calc_center_of_mass`/`calc_inertia` — проверено).

| Величина | Статус | Валидация |
|---|---|---|
| Объём | ✅ вычислен для **100/100** мешей (мировой + локальный) | `base_link` V_local = 0.078939 м³ |
| Центр масс | ✅ вычислен (мировой) | ЦМ base = центру bbox точно |
| **Тензор инерции** | ✅ вычислен **и валидирован** | `base_link` Ixx = **8.5305** vs аналитическое решение параллелепипеда **8.5232** кг·м² (Δ = 0.09 %), все диагонали положительны |

**Критические находки по масштабу:**
- 133/182 объекта с неединичным масштабом; **цепи рук несут `matrix_parent_inverse` ×1.2546**, которого **не видно в `obj.scale`** (там ≈1.0). Мировой det плеча = 1.977, ладони = 2.496.
- Stored-массы рецептур 2700/1200 использовали **V_local**, поэтому расхождение мировой/локальный объём = ровно 0.09 % (фактор масштаба 1.00086) — воспроизводится в массе: 213.317 (2700×V_world) vs 213.134 (2700×V_local).
- **Инвертированные нормали (отрицательный объём):** `torso_link`, `left_palm_link`, 9 фаланг левой руки, `stereo_microphone_1`, фаланги больших пальцев — требуют исправления перед геометрическим заполнением.
- Параметрическое правило: при неизвестной толщине/материале — оставлять `m = ρ·A(t)`, `I = f(ρ, t)` символьно, без подстановки точных чисел.
