## 2. Отказные режимы по архитектурам

| Режим | A (Local) | B1/B2 (ремень к плечу) | B3 (основание, через подъёмник) | C/D (с компенсацией) |
|---|---|---|---|---|
| **Отключение питания** | Тормоз каждого сустава должен держать выходной момент. Через неизвестный редуктор момент на тормозе не выводится → **требуется внешнее/независимое удержание** | Как A, но сустав, чей мотор уехал, держится через ДОПОЛНИТЕЛЬНУЮ передачу: обрыв ремня мгновенно снимает удержание этого сустава | **Худший:** обрыв/заклинивание на трассе через подъёмник снимает удержание СРАЗУ всех суставов, чьи моторы в основании | Как базовая архитектура, **плюс** энергия пружины: при обрыве крепления компенсатор выдаёт момент +10…+104 Н·м (остаток β=0.9 по sh1) в НЕПРЕДСКАЗУЕМОМ направлении |
| **Отказ одного двигателя** | Локальный: теряется один сустав, остальные удерживаются | Передача остаётся целой, но мотор не крутит → сустав свободен (если нет отдельного тормоза) | Двигатели в основании: отказ мотора не трогает механику трассы, но сустав теряет момент | Суммируется с эффектом компенсатора (см. выше) |
| **Отказ одного тормоза** | UNKNOWN (A16): наличие тормоза не определено. Если тормоза нет — удержание только моментом двигателя, что требует постоянного тока | То же + потеря натяжения ремня делает удержание через передачу невозможным | То же, но масштаб — вся рука | Компенсатор может частично удержать ПУСТУЮ руку (остаток 35…104 Н·м при β=0.9), но **не груз** |
| **Обрыв ремня/кабеля** | не применимо (нет передачи) | Прямое: сустав переходит в свободное вращение. Кабель (не ремень) имеет иной режим обрыва — **эквивалентными не считаются** | Обрыв на трассе → потеря нескольких суставов; возможен «свободный» сустав под грузом | Пружина продолжает действовать |
| **Разрушение пружины** | не применимо | не применимо | не применимо | Классический риск C/D: потеря компенсации = скачок момента на приводе. Если компенсатор работал как «половина веса», при его отказе привод должен выдержать **полный** момент — проектировать по полному Tg |
| **Заклинивание передачи** | локальное | Заклинение = сустав обездвижен; при этом редуктор воспринимает момент снаружи — нагрузка на зубья/кабель НЕ рассчитана | То же + заклинение на трассе через подъёмник может заблокировать подъём | Усложнено: две системы в одном узле |
| **Потеря положения (датчик)** | локальная ошибка одного сустава | Ошибка датчика на суставе при моторе у плеча → обратная связь через редуктор/ремень: люфт и гистерезис передачи ВНЫШНЕ добавляют ошибку (не рассчитаны) | То же, плюс изменяющаяся длина трассы на ходу подъёмника ≈1.2 м | + ошибка компенсации не измеряется датчиком напрямую |
| **Потеря удерживаемого груза** | при недостатке момента удержания | При обрыве ремня груз падает мгновенно; **время до отказа = время разрыва, а не время разгона** | Как B1/B2, но обрыв на вертикальной трассе | Пружина добавляет энергию в систему падения |
| **Непреднамеренный контакт с человеком** | Определяется МАКСИМАЛЬНЫМ моментом и скоростью. Макс. стат. момент 987 Н·м при 100 кг означает, что при отказе управления столько же может быть приложено к препятствию | Выигрыш по пустой руке (148 → 44 Н·м) снижает опасность в режиме БЕЗ груза — а это основной режим общения с пациентом | B3 не даёт выигрыша по моменту (889 Н·м при 100 кг) | Компенсация **не снижает** момент от внешней нагрузки (проверка V9) → безопасность контакта не улучшается |

## 3. Удержание при отключении питания — что требуется

1. **Тормоз двигателя нельзя считать достаточным.** Он указан в каталоге/спецификации
   (для локальных моторов) как момент на ВАЛУ; момент на ВЫХОДЕ сустава
   `T_вых = T_тормоз · i · η_rev`. Ни `i`, ни `η_rev` для предполагаемых приводов
   неизвестны → **достаточность не доказана** ни для одной архитектуры.
2. **Для нагрузок, связанных с поддержкой пациента, требуется независимое
   механическое удержание** (отдельный тормоз на выходном валу, фиксатор, или
   самотормозящаяся передача с подтверждённым η_rev < точек самоторможения).
   Статус: **не спроектировано** для всех вариантов A…D.
3. **Компенсатор не является удержанием** — он уравновешивает только собственный
   вес в пределах своего рабочего диапазона; при снятии питания и обрыве пружины
   момент на приводе не предсказуем по знаку.

## 4. Минимальные требования к тормозам (параметрически)

Требуемый момент тормоза на ВЫХОДЕ сустава ≈ максимальный статический момент
в режиме удержания (без динамической надбавки):

| Режим удержания | Требование на выходе сустава (A, nominal) |
|---|---|
| Пустая рука | до **148.2 Н·м** |
| Манипуляция 25 кг | до **344 Н·м** |
| Груз 100 кг | до **987 Н·м** |
| Контакт с пациентом 300 Н | до **392 Н·м** |

Перевод на тормоз двигателя `T_тормоз ≥ T_вых /(i·η_rev)` — **не выполним** без
`i`, `η_rev` (UNKNOWN). При `i=30`, `η_rev=0.8` (справочные значения Stage 2G,
НЕ спецификация этого привода) потребность составила бы 41 / 95 / 274 / 109 Н·м
на валу — эти числа приведены **только как ориентир масштаба** и не являются
требованием к изделию.

## 5. Сводка по архитектурам (безопасность)

| Архитектура | Удержание без питания | Отказ одного элемента | Типичный опасный сценарий | Статус данных |
|---|---|---|---|---|
| **A** | локальный тормоз на суставе (требует подтверждения) | теряется один сустав | макс. момент при грузе 987 Н·м | тормоза UNKNOWN |
| **B1** | локальный + целая передача | обрыв ремня = свободный сустав локтя | обрыв под нагрузкой | передача ASSUMED |
| **B2** | то же, 4 сустава через передачу | обрыв = 4 сустава | то же, шире по охвату | передача ASSUMED |
| **B3** | **все** суставы через одну трассу через подъёмник | обрыв/заклинение на трассе = вся рука | изменение длины трассы на ходу ≈1.2 м | ASSUMED, риск не рассчитан |
| **C** | тормоз + частичная компенсация пустой руки (остаток 35…104 Н·м) | разрушение пружины даёт скачок момента | обрыв крепления компенсатора | компенсатор ASSUMED |
| **D** | сумма рисков B и C | отказ одной системы меняет нагрузку на другую | двойной отказ | ASSUMED |

**Главный вывод по безопасности:** ни одна архитектура не может быть признана
безопасной для работы рядом с пациентом на имеющихся данных, потому что
**наличие, тип и момент тормозов не определены (A16)**, а КПД и передаточные
числа приводов отсутствуют. Для режимов поддержки пациента требуется
спецификация независимого механического удержания — это блокирующее требование,
общее для A, B, C и D.
