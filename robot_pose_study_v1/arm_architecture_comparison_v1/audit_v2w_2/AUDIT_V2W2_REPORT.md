### 0.1. Самокоррекция: скорость и мощность в Stage 2W.1

В Stage 2W.1 скорость сустава считалась как `q̇ = Δq·ṡ/T_LEG`, хотя `ṡ` уже имела
размерность 1/с (площадь трапеции `∫ṡ dt = 1`). Деление на `T_LEG` завышало скорости
на 25 %: в 2W.1 `q̇_max = 2.326` рад/с, в 2W.2 при том же профиле — **1.86 рад/с**.
Позиционный профиль при этом оставался корректным, то есть 2W.1 был внутренне
несогласован: `q(t)` и `q̇(t)` описывали разные движения.

Следствие: пики мощности 2W.1 несопоставимы напрямую с 2W.2. Сравнение — в §4.3.

## 4. П.4. Динамика и энергия цикла

### 4.1. Метод

Трапецеидальный закон сохранён: `T_LEG = 0.8 с`, `RAMP = 0.25`, 16 точек на переход.
В каждой точке вычислялись `q(t)`, `q̇(t)`, `q̈(t)`, `M(q)`, `c(q,q̇)` по Кристоффелю,
`Tg(q)`, `Text(q)`, `Tcomp(q)` и полный `tau_act`:

```
M·q̈ + c + Tg = tau_act + tau_spring + Text
tau_act = Tg + M·q̈ + c + Text − tau_spring
```

Энергобаланс проверялся по каждому переходу: `W = ∫tau_act·q̇ dt ≈ Δ(K + V + U)`.
Относительная ошибка по всем 10 прогонам — **0.27…0.38 %** (порог 5 %).
Нетто-работа замкнутого цикла `|W_net| ≤ 0.086 Дж`.

## 6. Ответы на пять вопросов

### 1. Сколько массы фактически снимается с подъёмника в B3-T и B3-B?

- **B3-T — 0 кг.** Вся масса остаётся на подъёмнике: 219.19 кг в модели

  ход ≈ 1.2 м, их КПД, жёсткость и безопасность — **UNKNOWN** и в баланс не входят.

### 2. Насколько уменьшаются плечевой момент и инерция при переносе целого двигателя локтя?

- Статика при 25 кг (B1 к A): sh3 −15.1 %, sh2 −22.3 %, **sh1 −20.0 %**
  (139.1 → 111.3 Н·м); максимум по суставам 257.7 → 218.8 Н·м.
- Инерция плеча при f = 0.5: **M_sh1 −39.7 %** (5.124 → 3.092 кг·м²),
  M_sh2 −34.8 %, M_sh3 −33.5 %.
- Диапазон по доле редуктора: M_sh1 −23.5 % (f = 0) … −55.8 % (f = 1).
- Инерция локтя от переноса не меняется (масса уходит с оси вращения);
  у B2 она даже растёт на 9.6 % из-за ремня запястья на предплечье.

### 3. Какие компенсаторы математически возможны, а какие требуют проверки конструкции?

- **Математически допустимы:** L/sh1 (k = −32.14, q0 внутри хода) — включён;
  L/rad и R/w2 — формально допустимы, но |k| < 1 Н·м/рад, эффект пренебрежим.

- **Несовместимы по знаку момента:** L/sh2, L/w2, R/sh3, R/sh2, R/el.
- Наиболее перспективен по доле компенсации пика L/sh3 (62 %), но он требует

- Архитектура C **не приговорена**: вывод относится только к линейной
