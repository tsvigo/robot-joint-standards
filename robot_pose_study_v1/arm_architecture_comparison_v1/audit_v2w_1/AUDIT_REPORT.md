## 4. П.4 — динамика и Кориолис

Кориолис пересчитан через символы Кристоффеля:

```
c_i = Σ_j Σ_k Γ_ijk·q̇_j·q̇_k
Γ_ijk = ½(∂M_ij/∂q_k + ∂M_ik/∂q_j − ∂M_jk/∂q_i)
```

Производные — по радианам (шаг `h_deg = h_rad·180/π`).

| Тест | Результат | Статус |
|---|---|---|
| `c(q, 0) = 0` | 0.00e+00 | PASS |
| `c(q, 2q̇) = 4·c(q, q̇)` | отношение 4.000000 | PASS |
| Энергосогласование `q̇ᵀc = ½q̇ᵀṀq̇` | −0.099977 = −0.099977 | PASS |
| Независимая проверка `dT/dt` | −0.099977 | PASS |

Старый `coriolis_vector()` в том же тесте давал |c| ≈ 0.001 Н·м (фактически
ноль) из-за формулы без двух множителей скоростей; новый — **0.93 Н·м**.

Масса груза включена в `M(q)`, если груз движется с кистью (точка начала
ладони). Инерции роторов и передач отсутствуют в данных → **UNKNOWN**, в
модель не входят.
