Контрольная точка: P7 R, c = 0.05 м, режим 6D, `finger_yaw = 80°`, `lift = 0`.
Источник траектории A: `stage2b1_unilateral_P7_R_c0.05.json`
(sha256 `d4c55c97…4947`), политика `strict_6d`.
Артефакты: `stage2b2_policy_p7r.json`, `stage2b2_policy_p7r_steps.csv`,

## 2. Самокоррекция к контрольному отчёту

В контрольном анализе (`STAGE2B2_CONTROL_P7R.md`) использовалось значение
`ms.MODE` по умолчанию — **5D**, тогда как артефакт 2Б.1 построен в режиме
**6D** (`stage2b1_unilateral.py:345`, `"mode": "6d"`).

Что это затрагивает:

- **Не затронуто** (зависит только от q и геометрии): запасы 1.562°/11.885°,
  замыкание 19.392°, шаги суставов, зазоры, евклидовы расстояния, число шагов
  манёвра, невязки. Эти числа подтверждены повторно в 6D.
- **Затронуто**: число обусловленности (строится по масштабированному
  якобиану, 5×7 или 6×7) и направление нуль-пространства при самодвижении.
  При пересчёте в 6D терминальное самодвижение даёт те же 42 шага, 36.52° и
  min зазор 0.1278 м (`arm_torso`) — выводы не меняются, но значения
  обусловленности из контрольного отчёта следует читать как 5D-оценки.

Исправленная политика и все дальнейшие расчёты выполняются в 6D.

## 3. Что изменено в политике

Старый `ik.solve_once` на каждой итерации добавлял член
`0.03 · N · limit_gradient`. Он не обнуляется при достижении позы и
накапливается между сэмплами; на последнем сэмпле перехода это давало шаг до
14.0° (евклид.) и уводило `w2` к 43.44° (запас 1.56°).

Новая политика разделяет две вещи, которые старый решатель смешивал:

1. **Трекинг позы** (`track_sample`) — только `J⁺e`, без нуль-пространственного
   члена, остановка при `‖e‖ ≤ 10⁻⁶`. Дрейфа нет по построению.
2. **Планирование избыточности** (`anchor_for`, `null_bias`) — затравка
   берётся из расписания между эталонными конфигурациями перехода
   `lerp(q_i, q_{i+1}, t)`, а остаточное смещение к якорю вводится явными
   шагами ≤ 0.35° за сэмпл (≤ 3 шагов в путевой точке) с обязательной
   перепроекцией на позу. Суммарно за цикл введено 0.35°.

Дополнительно:

- **Защита непрерывности**: если шаг от предыдущего сэмпла превышает 5°,
  решение перезатравливается от предыдущего q, и принимается только вариант,
  который ближе по q и удовлетворяет позе.
- **Fallback**: при невязке позы > 0.01 мм сэмпл перепроецируется от якоря.
  В итоговом прогоне fallback не потребовался (0 сэмплов).
- Якорь «фиксированный стартовый q» проверен как альтернатива и **отвергнут**:
  он борется с задачей, упирает `sh3` в предел 60° и даёт невязку 73.5 мм
  (вариант `start` в JSON).

## 4. Валидатор шага

Порог 3–5° используется как диагностический: `ok` < 3°, `refine` 3–5°,
`anomaly` > 5°. Запрета нет — интервал с большим шагом просто дробится при
сертификации и проверяется отдельно.

Для каждого из 74 интервалов нового цикла записаны: шаг каждого сустава,
евклидова норма Δq, перемещение точек звеньев, перемещение кисти, невязка
позы до/после, запас до/после, классификация (`task_tracking` /
`injected_self_motion` / `waypoint`).

| Показатель | Новый цикл | Старая траектория + манёвр |
|---|---|---|
| Интервалов | 74 | 117 |
| Макс. шаг по суставам | `el` 2.00°, `sh2` 1.74°, `w1` 1.73° | `sh1` 8.42°, `rad` 6.52°, `sh2` 5.53° |
| Макс. ‖Δq‖ | 3.39° | 14.00° |
| Макс. перемещение звеньев | 11.56 мм | 30.0 мм |
| Макс. перемещение кисти | 10.00 мм | 10.0 мм |
| `refine` / `anomaly` | 0 / 0 | 0 / 1 |

Перемещение кисти 10.0 мм на сэмпл — это и есть шаг задания
`CART_STEP_M = 0.01`; политика его не увеличивает.

## 5. Межсэмпловая сертификация

Для каждого интервала вычисляется консервативная граница перемещения точек
звена за один интервал:

```
bound = 1.05 · Σ_j |Δq_j| · max|∂p/∂q_j|
```

где максимум берётся по концам и середине интервала (конечные разности 0.05°).
Расстояние между телами 1-липшицево по положениям точек, поэтому
`min(clearance на концах) − bound > 0` сертифицирует интервал.

**Предположения, при которых вывод справедлив:**

1. Между сэмплами суставы движутся линейно по q (закон по времени не задан,
   поэтому о скоростях и ускорениях утверждений нет).
2. Геометрия руки — капсулы `bed.arm_segments`; окружение — бокс кровати,
   корпус, база, вторая рука в парковке P0. Это упрощённая модель.
3. Максимум градиента по интервалу покрывается тремя точками с коэффициентом
   1.05 — это численное допущение, не доказательство.
4. Если граница не сходится, интервал дробится (до глубины 4); несошедшиеся
   помечаются `undefined`.

Результат нового цикла: **74/74 сертифицировано, `undefined` = 0**,
дробление не потребовалось (в старом пути — 1 интервал с дроблением до 4
листьев). Минимальный зазор 0.068064 м (`arm_bed`), минимальный остаток
`clearance − bound` = 0.0399 м.

Формулировка: это **численная проверка** при перечисленных предположениях, а
не «гарантированно collision-free» и не подтверждение безопасности с пациентом.

## 6. Ограничения

- Одна операция, одна рука, одно расстояние до кровати (P7 R, c = 0.05 м).
- Критерии 1.0 мм / 0.5° — исследовательские допуски, не требования к роботу.
- Политика не проверена на P6, на левой руке и на c = 0.10 м.
- Двухручные столкновения не проверялись (вторая рука в парковке).
- Силовые расчёты не выполнялись; конструкция и `.blend` не изменялись.
- Запас 4.063° — лучший из трёх сошедшихся статических решений S2_contact, но не
  доказанный предел позы: более плотный поиск многообразия избыточности остаётся
  задачей фазы выбора ветвей. Если он найдёт точку с большим запасом, расписание
  избыточности можно будет сдвинуть без изменения поз и замыкания цикла.
