## 6. Межсэмпловая сертификация зазоров

**Метод:** линейная интерполяция q между сэмплами → капсулы звеньев → градиенты расстояния в 3 точках (концы + середина) ×1.05 → 1-липшицевость расстояний → `min(clearance) − bound > 0` сертифицирует интервал.

**Предположения (явно):**
1. Суставы движутся линейно по q (нет закона времени → нет скоростей/ускорений).
2. Геометрия: капсулы `bed.arm_segments`, кровать/корпус/база — AABB.
3. Максимум градиента по интервалу покрывается 3 точками ×1.05 — **численное допущение**.
4. Если не сходится → рекурсивное дробление до глубины 4 → `undefined`.
5. Это **численная проверка**, не строгая математическая гарантия и не подтверждение безопасности с пациентом.

**Результаты:** все интервалы сертифицированы (64/64 или 74/74), `undefined` = 0. Мин. остаток `clearance − bound` = 0.0056 м (P6 c=0.10) … 0.04 м.
