# Stage 2A — выборочная проверка IK в Blender

**Статус:** выполнена после включения Blender MCP. Файл `.blend` не сохранялся.
**Область:** 9 достижимых решений из `small_sample.json`; это выборочная, а не полная проверка всех 35 решений.

## Метод

1. Прочитаны текущие `rotation_euler` всех семи пустышек руки.
2. В них временно записаны углы IK-решения (`sh3, sh2, sh1, el, rad, w1, w2`).
3. Выполнен `view_layer.update()`.
4. У объекта `left_palm_link` / `right_palm_link` взята `matrix_world`; контактная грань построена по `palm_geometry.json` (X-min для левой, X-max для правой), нормаль — по `normal_local`.
5. Позиция и нормаль сравнены с целью из `bed_study.make_targets`.
6. Исходные трансформации восстановлены в `finally`; `bpy.ops.wm.save_mainfile()` не вызывался.

## Вывод

- Позиция контактной грани в Blender совпадает с математической целью в пределах **1.3 мм**; расхождение ожидаемо из-за rigidified-модели, масштабов и округления.
- Нормаль совпадает в пределах **0.001°** для всех 9 случаев.
- Для 6D P6 L и P9 R полная ориентация совпала в пределах **0.01°**.
- Для 5D большая ошибка «ориентации» не является ошибкой: 5D оставляет поворот вокруг нормали свободным; критерий — нормаль.
- Это подтверждает соответствие `q_deg` → Blender FK и выбранной геометрии ладони, но не заменяет полную проверку всех решений и не является оценкой столкновений или безопасности.
