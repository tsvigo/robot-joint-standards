## 2. Постановка IK

- 7-DOF рука, целевая точка — контактная грань ладони.
- **6D:** позиция + полная ориентация ладони.
- **5D:** позиция + заданная нормаль ладони; вращение вокруг нормали свободно.
- Лимиты суставов учитываются; решения вне лимитов отбрасываются.
- Избыточность используется через null-space: смещение от лимитов и дополнительные решения.
- Несколько стартов: `P0`, `forward_bent`, `folded`, нулевая поза, случайные старты, смещения `w1`, null-space ±3°/±6°.
- Лучшее решение выбирается только среди сошедшихся валидных: сначала запас до лимитов, затем `cond`, затем ошибки.
- В выборке над кроватью из валидных решений предпочитается решение без пересечений в упрощённой модели.

### 2.2. Единицы и нормировка `cond`

- Позиционные строки якобиана: м/рад.
- Ориентационные строки: рад/рад.
- Для `cond` позиционные строки делятся на `L_norm = 0.5 м`; ориентационные и нормальные строки остаются без изменений.
- 6D: анализ по 6×7 якобиану.
- 5D: анализ по 5×7 якобиану (позиция + нормаль, спроецированная на касательную плоскость); решатель 5D использует 6-строчный residual с signed normal.
- `cond` — сравнительная метрика. Универсальный порог не применяется; высокий `cond` сам по себе не означает недопустимость, низкий — не гарантирует безопасность.

| Параметр | Значение |

Подходы:

- **Боковой:** длина кровати вдоль `Y`, ширина вдоль `X`; робот стоит сбоку.

Робот не предполагается способным подъехать вплотную: зазор задан явно. При зазоре 0.10 м ближний край кровати находится на `x = 0.435 м`.

## 5. Что именно достижимо

### 5.1. P4 — ближний край

- P4 L 5D достижима при H = 0.6–0.9 м и W = 0.9–1.2 м, зазор 0.10 м; запасы 3.3–23.0°, `cond` 5.1–6.9.
- P4 L при зазоре 0.05 м **не найдена** (остаток 8 мм); при 0.15/0.20 м достижима. Слишком близкое положение базы ухудшает near-edge позу, а не улучшает её автоматически.
- P4 R 5D при H = 0.7 м **не найдена** (лучший остаток 61 мм; `sh3` у верхнего лимита 60°, `rad` у 90°, `w2` у −23.3°).
- P4 R 5D при H = 0.8 м достижима с запасом всего 0.42°; при H = 0.9 м запас 13.1°.
- P4 R 6D: при H = 0.8 м достижима только при направлении пальцев `+Y` (запас 0.57°); при H = 0.9 м не найдена ни при `+X/-X/+Y/-Y` (лучший остаток 2.3 мм / 0.21°).
- P4 L 6D при H = 0.7 м не найдена ни при четырёх направлениях пальцев; 5D при той же точке достижима.

Вывод: «P4 достижима» верно не для всей линии ближнего края. Для правой руки при низкой кровати нужен либо подъём, либо другое размещение/ориентация; это предварительный вывод, требующий широкого поиска.

### 5.2. P5 — дальняя сторона

P5 не найдена ни в одной из 38 строк, включая 30 случайных стартов для ключевых конфигураций.

Геометрическая оценка:

- Длина руки плечо → центр ладони: ≈0.974 м (L), ≈1.003 м (R).
- При W = 0.9 м и зазоре 0.10 м цель P5 находится примерно в 1.05 м от плеча (по прямой), ещё до учёта ориентации и запястья.
- При W = 1.0/1.2 м расстояние только растёт.

Это уже за пределами идеальной сферы руки, поэтому P5 — **геометрический предел**, а не просто плохой старт. Формулировка «недостижима при текущей базе и зазоре» подтверждена расчётом; «недостижима ни при какой конфигурации робота» — нет.

## 6. 6D: почему нельзя читать таблицу как «6D почти не работает»

В базовой выборке 6D использовалась **одна** ориентация на позу: P4 `+X`, P6 `+X`, P7 `+Y`, P9 `+Y`. Это не полный перебор ориентаций. Фокусные проверки четырёх направлений пальцев дали:

| Случай | `+X` | `-X` | `+Y` | `-Y` |
|---|---|---|---|---|
| P4 L H=0.7 | нет | нет | нет | нет |
| P4 R H=0.8 | нет | нет | **да, запас 0.57°** | нет |
| P4 R H=0.9 | нет | нет | нет | нет |
| P7 L H=0.7 | **да, запас 9.17°** | нет | нет | нет |
| P9 L H=0.7 | **да, запас 1.63°** | нет | нет | нет |
| P6 L H=0.7 | **да, запас 31.1°** | нет | нет | нет |
| P6 R H=0.7 | **да, запас 9.44°** | нет | нет | нет |

Следствие: 5D — более устойчивая метрика доступности точки; 6D нужно исследовать с несколькими допустимыми ориентациями пальцев/кисти, а не с одной произвольной. В отчёте 6D-отказы помечены как «не найдено при данной ориентации», а не «недостижимо вообще».

## 7. Упрощённая проверка столкновений

Модель:

- капсулы звеньев: плечо 0.060 м, плечевое звено 0.047 м, предплечье 0.047 м, кисть 0.030 м;
- торс — oriented box 0.32 × 0.26 × 0.10 м;
- база — AABB 0.67 × 0.67 × 0.176 м;
- кровать — AABB по параметрам;
- расстояния до box — 21 точка на сегмент; между руками — segment-segment.

Ограничения:

- это не исходные collision-меши;
- нет пациента, постели, поручней, рамы, мягких контактов;
- проверка «рука-рука» использует вторую руку в P0, а не совместное решение;
- отрицательный зазор означает пересечение только в этой упрощённой модели.

Для 35 достижимых строк минимальный зазор 0.048 м; пересечений не найдено. Это **не** запас безопасности: геометрия упрощена, а контакт с пациентом/постелью не моделировался.

## 8. Обусловленность

- Среди 35 достижимых строк максимальный `cond` = 43.3 (P7 L 5D); большинство решений 3.6–10.9.
- У недостижимых строк `cond` часто тысячи (например, P5 R до 4.1e4), но это `cond` лучшего остаточного решения, а не рабочей позы.
- `cond` не использовался как универсальный порог; он служит сравнительной метрикой и одним из критериев выбора среди валидных решений.
- Для 5D и 6D `cond` считается по разным analysis Jacobian; сравнивать их между собой без оговорки нельзя.

## 10. Недостижимые зоны и предварительные выводы

1. **P5, дальняя сторона** — не достижима при текущей длине руки, ширине 0.9–1.2 м и зазоре 0.10 м. Нужен более близкий подъезд (но он ухудшает P4), доступ с дальней стороны, наклон/выдвижение корпуса или изменение длины руки. Это не решается только подъёмом.
2. **P4 справа при низкой кровати** — H=0.6–0.7 м не достижима в 5D; H=0.8 м — на пределе (0.42°); H=0.9 м — комфортнее. Подъём 0…+100 мм может помочь, но это ещё не проверено.
3. **6D у P4/P7/P9** — сильная зависимость от ориентации кисти; одна ориентация не является доказательством недостижимости. Нужен перебор допустимых ориентаций и, возможно, изменение диапазона запястья.
4. **P7 L** — запас 1.54° и `sh1` почти на нижнем лимите; поза не является удобной для длительной работы.
5. **P9 R 6D** — запас 0.0°; как рабочая поза не годится без запаса, даже если FK сошёлся.
6. **Фронтальный подход** — на базовой конфигурации даёт только P4 L 5D и P6; дальние точки и P9 у дальнего конца не достижимы.
7. **P8, совместные позы, лифт** — ещё не исследованы. P8 должен проверяться только геометрически; силовой контакт не моделируется.
