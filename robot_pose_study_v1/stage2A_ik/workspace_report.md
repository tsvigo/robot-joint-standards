## 1. Что и как считалось

### 1.1. IK и проверка

- 🟢 5D: задаётся позиция контактной грани ладони и нормаль; ориентация вокруг нормали свободна.
- 🟢 6D: задаётся полная ориентация; в широком поиске проверены четыре направления пальцев: `+X`, `-X`, `+Y`, `-Y`.
- 🟢 Для каждой цели — несколько стартов, damped least squares, лимиты суставов, null-space, отбор решений по запасу до лимитов, затем по `cond`, затем по ошибкам.
- 🟢 `cond` — по масштабированному analysis Jacobian: позиционные строки делятся на 0.5 м; 5D — матрица 5×7, 6D — 6×7. Это сравнительная метрика; универсального порога нет.
- 🟢 FD-проверка якобиана: 28/28, max abs `2.796e-9`, max relative `2.104e-9` (см. `control_report.md`).
- 🟢 Контрольная IK-валидация: 48/48 известных поз, 46/48 случайных, 727 решений; лучшие ошибки — 0.0028 мм и 0.0002°.
- 🟡 Одна строка P7 L 5D (H=0.7, W=1.0, c=0.15) при быстром поиске имела остаток 0.0089 мм / 0.0007°, но не прошла строгий `task_error_norm`. Полный `solve_bed_target` нашёл валидное решение: запас 2.64°, `cond` 37.09. В JSON это отмечено в `refinements`. Остальные недостижимые строки имеют существенно большие остатки, а не только численный недобор.

### 1.2. Кровать, база и подходы

- 🟡 Параметрическая кровать: длина 2.0 м (допущение), высоты 0.6/0.7/0.8/0.9 м, ширины 0.9/1.0/1.2 м.
- 🟡 Зазор между базой и кроватью: 0.05/0.10/0.15/0.20 м. Робот не предполагается вплотную к кровати.
- 🟡 Боковой подход: длина кровати вдоль Y, робот сбоку по X.
- 🟡 Фронтальный подход: длина кровати вдоль X, робот у головного/ножного торца; цели P7/P9 оказываются далеко вдоль кровати.
- 🟢 База: half-x/half-y 0.335 м, z 0.0466…0.2226 м; параметры взяты из модели, не подгонялись под результат.

### 1.3. Столкновения

- 🟡 Временная упрощённая геометрия: капсулы звеньев, oriented box торса, AABB базы и кровати.
- 🟡 Нет пациента, постели, поручней, исходных collision-мешей и динамической геометрии.
- 🟡 Для одиночных строк вторая рука стоит в P0; это не совместная поза.
- 🟢 Для совместных поз и P8 проверены обе руки одновременно; дополнительно посчитан зазор «рука–рука» без плечевых сегментов (distal), потому что общий минимум часто определяется плечами и не показывает сближение кистей.
- 🔴 «Collision-free» здесь означает только отсутствие пересечения в этой упрощённой модели. Это не безопасность.
