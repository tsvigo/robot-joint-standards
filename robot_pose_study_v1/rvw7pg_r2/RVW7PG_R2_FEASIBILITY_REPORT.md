## 2. Задача 2 — тяга, мощность, нагрев
(`/home/v/projects/робот/robot_pose_study_v1/rvw7pg_r2/rvw7pg_r2_loads.py|.json`, 4/4 PASS)

Методика — формулы каталога (DOC, стр.35–38): `Tw = W/4·(a + 9.8·Crr·C)·Dw/2·10⁻³`
(плоскость), со склоном `+9.8·(sinθ + Crr·C·cosθ)`; C: вперёд/вращение 1,
traverse 2, diagonal 2.5 (диагональ на склоне запрещена производителем);
`Tm = (Tw/0.95 + T_no)/i`; ограничения Tw ≤ 27 (acc/dec), крейс ≤ 7 (rated).

- **Вертикальные нагрузки (CALC):** 300/400/450 кг → равн. 75/100/112.5 кгс;
  перекос ×1.5 → 168.8 кгс (450); потеря опоры → 150 кгс — **всё ≤ 200 кгс PASS**;
  правило 3/4: **450 < 600 кг PASS**.
- **Сетка (CALC):** 3 массы × 5 ускорений × 5 уклонов × 4 режима = **240 точек**;
  **Tw > 7 Н·м: 191; Tw > 27 Н·м: 0**; максимумы: боковое 22.63, вперёд/вращение
  17.73, диагональ (плоскость) 17.28 Н·м.
- **Крейс (a=0, плоскость):** 3.27/4.37/4.91 Н·м — ≤7 PASS для всех масс.
- **Удержание (a=0, 450 кг):** 1% → 5.89 (≤7); 3% → 7.85; 5% → 9.81; 8% → 12.73 Н·м
  (все ≤27, но >7 — кратковременный режим/согласование).
- **Мощность (CALC, η=0.95 DOC):** крейс @0.5 м/с: 18.4/24.6/27.6 Вт на выходе;
  потери редуктора 1.0–1.5 Вт; при 1.0 м/с и макс. сетки (22.63 Н·м) — сотни Вт
  (в JSON).
- **Момент мотора:** Tm = (Tw/0.95 + T_no)/i; при Tw=22.63, T_no=1.5 (UNK-оценка):
  Tm ≈ 0.84 Н·м — требует подтверждения мотора по каталогу Nabtesco (выбор
  мотора: стр.33–38).
- **Нагрев:** модель параметрическая; блокеры: T_no (только график), η/потери
  мотора, R_th, допустимый ток/длительность; сценарии 15/30/60 мин — **время до
  60°C НЕ вычислимо**.
- **Тормоз (DOC/UNK):** тормоз в модуле НЕ упомянут; удержание на уклоне моментом
  мотора ≤7 (1%) / 7–27 Н·м (3–8%); независимый стояночный тормоз или аутригеры —
  **решение не принято**; медицинское требование Nabtesco (индивидуальная проверка).

**Итог задачи 2: DRIVE — CONDITIONAL.** Тяга: PASS по 200 кгс и ≤27 Н·м во всей
сетке; НО непрерывный крейс ≤7 подтверждён только для плоскости, удержание ≥3%
при 450 кг >7; мощность: PASS-порядки (десятки Вт крейс); нагрев: NOT CONFIRMED;
тормоз: NOT CONFIRMED.

## 3. Задача 3 — радиальная схема с 4 одинаковыми колёсами
(`/home/v/projects/робот/robot_pose_study_v1/rvw7pg_r2/rvw7pg_r2_kinematics.py|.json`, 7/7 PASS)

- **Исполнения (DOC):** torsion code **L/R — два типа barrel orientations**
  (каталог, стр.9); заказ 4 шт одного кода (LLLL или RRRR) возможен по кодировке;
  спецификация «RVW-7PGLA-30 / RVW-7PGRA-30» на чертежах. Ограничения установки,
  допустимость радиальных осей, нестандартные конфигурации — **в каталоге не
  описаны** (только стандартные прямоугольные схемы со скоростями колёс W1–W4).
- **Кинематика (CALC):** J_i = [cos(θ+45σ), sin(θ+45σ), σ·R_C·sin45],
  θ = 0/90/180/270, σ = L(+1)/R(−1). **Регрессия против v7.1: omega
  (±8.333, −1.845871) и force (0.3536/1.5961) — 7/7 PASS в точности**;
  16/16 рангов совпали: **LLLL и RRRR — rank 3** (cond 1.0 по явной нормировке),
  смешанные — rank 3 (cond 2.414), **LRLR и RLRL — rank 2 (сингулярны)**;
  эталон X из v7.1: rank 3, cond 1.206 (без пересчёта — ê-модель верифицирована
  только для радиальной схемы). Расхождение cond с v7.1 (1.129 vs 1.0) — разная
  нормировка, зафиксировано, не интерпретируется.
- **Сила на колесо при M_z=1 Н·м:** 1.596 Н (R_C=0.2215), 1.349 Н (R_C=0.262) —
  расчётное распределение (CALC), не проверено стендом.

## 4. Ответ на итоговый вопрос

**Можно ли выбрать четыре Nabtesco RVW-7PG для R2 вместо RoboCT CTM1000-10R,
не теряя тяговых характеристик, безопасности и прохода через дверь 700 мм?**

**NOT CONFIRMED — подтвердить сейчас нельзя.** С доказательствами:

🟢 **Что подтверждено:**
1. Габарит: колёса Ø178 в Ø620 с запасом (CAD: зазор панель 10 мм, соседи 65 мм);
   проход 700 мм платформой не хуже RoboCT (Ø620 < 700).
2. Нагрузка: 450 кг во всех режимах ≤ 200 кгс/колесо и < 600 кг (правило 3/4, DOC).
3. Момент: вся сетка 240 режимов ≤ 22.63 Н·м < 27 Н·м (DOC acc/dec); крейс ≤7 Н·м
   на плоскости для 300/400/450 кг.
4. Кинематика LLLL/RRRR: ранг 3 с регрессионной проверкой (omega/force = v7.1).

🔴 **Точные блокеры (без них — без условного PASS):**
1. **Габарит мотора:** требование L_m ≤ 66 мм (до подъёмника Ø240 при RW=262) —
   мотор не выбран; чертежи motor flange за логином → полная длина сборки UNK.
2. **Тормоз:** в документации отсутствует; fail-safe удержание не подтверждено;
   удержание ≥3% при 450 кг превышает 7 Н·м непрерывно.
3. **Тепловые данные:** непрерывная работа 15/30/60 мин не подтверждаема
   (нет η, R_th, допустимого тока/длительности).
4. **Радиальная схема:** не описана производителем; требуется письменное
   подтверждение + осевые ограничения/ресурс при радиальных осях.
5. **Медицинское требование каталога:** применение в medical equipment требует
   индивидуальной проверки Nabtesco (DOC) — обязательный шаг, не формальность.
6. **Вердикт по компоновке:** NO FIT при параметрах мотора 80×100 мм
   (пересечение 78 663 мм³ с подъёмником) — путь только CONDITIONAL (L_m≤66).

Сравнение с RoboCT (масса модуля 25→~13–15 кг, Ø240→Ø178, 1000→200 кгс) и
решение о выборе — после ответа Nabtesco и подтверждения тормоза/тепла.
