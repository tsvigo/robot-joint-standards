## 2. Исправление CAD-компоновки (задача 2)

Новый файл: `/home/v/projects/робот/robot_pose_study_v1/rvw7pg_r2/rvw7pg_r2_layout_v2.py`
→ `rvw7pg_r2_layout_v2.FCStd` (SHA16 `b0424e19b08a6a41`), `.json`. Прежний
`rvw7pg_r2_layout.FCStd` НЕ изменялся.

**Подтверждены ошибки прежней компоновки (независимая проверка заказчика):**
1. Выход за Ø620: при R_w=262 наружный торец Ø178×96 имел точку
   sqrt(310²+89²)≈322.5 мм — **BoundBox-критерий был недостаточен** (углы
   цилиндра). Отозван вывод прежнего отчёта «наружный край 310 ≤ 310 ✓».
2. Панель после вырезов — несколько отдельных тел (у заказчика 5) → **FAIL**;
   прежняя панель не использовалась как подтверждение структуры.

**Исправления (проверено OpenCascade самостоятельно):**
- Пересчёт: RW_max = sqrt(310²−89²)−48 = **248.95 мм** → принято **RW=248.9**;
- реальный критерий габарита — `shape.cut(цилиндр R310).Volume`:
  **вне Ø620 = 0.0 мм³ для всех 6 тел** (панель, подъёмник, 4 модуля);
- связность: **панель = 1 Solid** (PASS) после новых ниш от x_notch0=112.9 мм;
- коллизии (подвеска 0): панель — 0 мм³ (зазор 10.0), подъёмник — 0 мм³
  (**зазор 2.9 мм**), соседи — 0 мм³ (зазор 120.1); подвеска ±15/±30 — без
  коллизий (панель 10.0, подъёмник 2.9 мм);
- **моторная зона пересчитана: L_m_max = RW − 76 − 120 = 52.9 мм** (без
  зазора). Прежний вывод «двигатель ≤66 мм — единственный блокер» **отозван**;
- исследовано вертикальное разнесение: при z_lift0 ≥ **137 мм** (выше верха
  моторной зоны 127 мм) конфликт снимается без ограничения L_m — требует
  согласования хода подъёмника (параметр конструкции, не утверждён).

**Вердикт задачи 1: CONDITIONAL** (при параметрах мотора 76×50 мм коллизий нет;
но L_m ≤ 52.9 мм — крайне короткий мотор; полный габарит с тормозом/креплениями/
кабелями не проверен → FIT невозможен). Статус прежнего вердикта «NO FIT при
80×100» сохранён для старой геометрии и не переносится.

## 3. Пересчёт приводных режимов радиальной R2 (задача 3)

Новый файл: `/home/v/projects/робот/robot_pose_study_v1/rvw7pg_r2/rvw7pg_r2_forces_v2.py`
→ `.json`. Модель — принцип виртуальной работы: равновесие Σf_i·ê_i = F·v̂ при
решении f_i = (ê_i·v̂)·F/2; **tесты 7/8 PASS** (T6b — содержательное превышение, см. ниже).

**Проверки согласованности:**
- **Мощности:** P_приводов = Σ f_i·u_i = F·v — точно, для всех 24 направлений (T3 PASS);
- **симметрия X/Y:** |u_i| и распределения идентичны → **C(X)=C(Y)=1**; каталожные
  C=1/2/2.5 относятся к прямоугольной компоновке и к радиальной не применимы (T1 PASS);
- изотропна МОЩНОСТЬ, но не распределение: max|f_i| = 0.354·F по осям X/Y и
  **0.5·F вдоль ê (диагональ)** — худший случай в √2 раз (T2 PASS);
- коэффициент √2 — геометрия косого контакта; **реальные потери Mecanum —
  параметр k_mec ≥ 1 (не измерены)**.

**Сетка (300/400/450 × a 0–0.5 × уклон 0–8%, r=0.089 м, R_w=0.2489 м):**

| | ≤7 Н·м | 7..16 | 16..27 | >27 |
|---|---|---|---|---|
| вдоль осей X/Y | 7 | 50 | 18 | **0** (макс 25.08) |
| худшее (диагональ) | 1 | 34 | 33 | **7** (макс 35.47) |

- **Крейс X/Y (a=0):** 4.63 / 6.17 / **6.95** Н·м (300/400/450) ≤ 7 rated (T7 PASS);
- **крейс по диагонали 450 кг: 9.82 Н·м > 7** — непрерывная диагональ ограничена;
- **удержание 450 кг:** 1% → 8.33; 3% → 11.11; 5% → 13.87; **8% → 18.0 Н·м**
  (при лимите 16 — превышение; при 27 — в пределах);
- **длительное боковое/диагональное** вдоль осей при 300/400/450:
  4.63/6.17/6.95 Н·м — ≤7 и ≤16 (PASS), при 450 упирается в rated;
- **скорости колёс:** комбинированное v=1.0 м/с + ωz=1 рад/с → max **94.8 об/мин**
  ≤ 107.3 (DOC); боковое по симметрии то же (T4/T5 PASS); регрессия Ø240 для
  Ø178 **не используется**;
- **пределы:** X/Y максимум 25.08 ≤ 27 (Rev.004.1) — но 17/75 точек > 16
  (Product Guide) → 27 Н·м не гарантирован (T6 PASS); **худшее направление:
  7/75 точек > 27 (макс 35.47 при 450 кг, a=0.5, 8%) — T6b FAIL: даже по
  Rev.004.1 диагональные предельные режимы выходят за кратковременный предел**
  (модельное предупреждение: расчёт идеальный, k_mec=1);
- **вертикальная нагрузка:** 168.8 кгс (перекос ×1.5) и 150 кгс (потеря опоры)
  ≤ 200 кгс — но «450 < 600 кг» из каталога **НЕ является доказательством
  устойчивости и допустимости ударных нагрузок** — ударные пределы производителем
  не опубликованы (открытый вопрос).

**Отзывы прежних выводов RVW7PG_R2_FEASIBILITY_REPORT:** ① «максимум 22.63 < 27
всей сетки» — верно только для каталожных C прямоугольной схемы; для радиальной
худший случай 35.47 Н·м; ② «боковое C=2» — не применимо (симметрия даёт C=1,
но ×√2 косого контакта); ③ «двигатель ≤66 мм» — заменено на ≤52.9 мм.
