## 1. Исправление масштаба скорости и момента

**Вывод преобразования (геометрия контакта, ролики 45°):** перемещение точки
качения вдоль жёсткого направления ê равно проекции окружного смещения на ê:
`ds = r·cos45·dφ`. Отсюда единая пара:

- `omega_i = √2·u_i / r` (u_i = J_i·twist),
- `T_i = f_i · r / √2`,
- энергия: `T_i·omega_i = f_i·u_i` → **Σ T_i·omega_i = Fx·vx + Fy·vy + Mz·wz**.

Проверено НЕЗАВИСИМО, не подстановкой: **6 энергетических тестов PASS в точности**
(поступательное X/Y/диагональ/произвольное, вращательное, комбинированное:
ΣTω = 100.000000000, 100.000000000, 70.710000000, 73.000000000, 40.000000000,
140.000000000 — эталону равны точно). Ошибка v2 (omega=u/r, T=f·r): произведение
верно, но обе величины масштабированы неверно (√2); на классике видно по
скорости X: v2 давала 0.707·v/r вместо v/r.
