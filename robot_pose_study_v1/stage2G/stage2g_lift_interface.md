## 2. Посадочное место (компоновочное решение)

```
        +Z (вверх, колонна лифта)
         │
   ──────┴─────── плита/каркас базы, z = +88 (верх базы) или внутренняя полка
         │        центр: (+0.003, −4.41)
   ══════╪═══════ кольцевая зона R_lift (параметр)
         │        2 винта + 2 направляющие + двигатель + тормоз + синхровал
   ──────┴─────── дно базы z = −88
         │
       (пол)
```

**Посадочная зона:** кольцо вокруг оси (+0.003, −4.41) в плоскости верхней плиты (z = +88) или внутренней полки. Радиус `R_lift` и `Ø_plate` — параметры (реальные размеры неизвестны).

**Сквозной проём:** колонна подъёмника проходит через всю высоту базы (176 мм) — в плите необходим проём `Ø_hole` (параметр ≥ наружный габарит колонны).

| Узел | Требуемая зона | Совместимость | Статус |

| Тормоз (`lift_brake`) | на двигатель/винт | в зоне колонны | ✅ компоновочно |
| Синхровал (`lift_sync_shaft`) | горизонтально между винтами | поперёк колонны-зоны | ✅ компоновочно |

## 4. Несовместимости / открытые вопросы

1. **Размеры узлов неизвестны** — `R_lift`, `Ø_hole`, `Ø_plate`, расположение крепежа: параметры до спецификаций (A6 из `STAGE2G_SOURCE_DATA.md`).
2. **Аварийный ловитель** — в Blender только placeholder; требования к нему не заданы → конструктивное решение на согласование.
3. **Точность оси** — сварной вариант каркаса (вариант B) может деформироваться при сварке → для варианта B требуется контроль плоскости посадки.
4. **Нагрузка на посадку** — моменты и силы от рук не рассчитывались (ограничение этапа) → сечение плиты/профиля посадки не назначается.
