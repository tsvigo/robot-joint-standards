## 1. Задача 1 — независимый кинематический аудит радиальной схемы (v4)

**Вывод уравнения (не перенос формулы обычной платформы).** Ось колеса `â_w`, направление
качения `t̂ = ẑ × â_w`. Спин `ω_i` даёт скорость точки контакта `ω_i·r·t̂`. Ось ролика в
точке контакта `â_r = (â_w + h·t̂)/√2`, `h = ±1` — рука ролика. Ролик свободен вдоль `â_r`,
качение без проскальзывания перпендикулярно `â_r`:

```
(V_i + ω_i·r·t̂) · â_r = 0   =>   V_i·â_w + h·V_i·t̂ = −h·r·ω_i,
V_i = (Vx − ωz·y_i , Vy + ωz·x_i).
```

Для радиальной схемы (колёса на θ = 0/90/180/270°, ось = радиус `r̂`, позиция `R_c·r̂`)
строка матрицы M (столбцы Vx, Vy, ωz):

```
[ cosθ − h·sinθ ,  sinθ + h·cosθ ,  h·R_c ] ,  правая часть = −h·r·ω_i.
```

### 1.1. Раскладка рук v4 (LRLR: L на 0/180°, R на 90/270°) — СИНГУЛЯРНА

```
M = [ 1   1   R ]      ранг(M) = 2
    [ 1   1  −R ]
    [−1  −1   R ]
    [−1  −1  −R ]
```

- **Оси роликов всех четырёх колёс лежат на ОДНОЙ прямой:** (0.707, 0.707), (0.707, 0.707),
  (−0.707, −0.707), (−0.707, −0.707). Все колёса ограничивают одно и то же направление.
- **Свободное (неуправляемое) движение:** `null(M) = (0.707, −0.707, 0)` — платформа
  свободно скользит по диагонали 135°/−45° при неподвижных колёсах.
- **Управляемо только 2 степени:** поступательно по (1, 1)/√2 и вращением ωz.
- **Два режима проскальзывания** (связи на скоростях колёс): из `null(Mᵀ)` следуют две
  линейные комбинации скоростей, при нарушении которых колёса обязаны проскальзывать.
- Итог: **это не четырёхколёсная X-схема Mecanum** — она не обладает полной управляемостью.

### 1.2. Полный свип 16 раскладок рук (схема R)

| Руки (0/90/180/270) | LLLL | RLLL | LRLL | RRLL | LLRL | **RLRL** | LRRL | RRRL |
|---|---|---|---|---|---|---|---|---|
| ранг | 3 | 3 | 3 | 3 | 3 | **2** | 3 | 3 |
| Руки | LLLR | RLLR | **LRLR** | RRLR | LLRR | RLRR | LRRR | RRRR |
| ранг | 3 | 3 | **2** | 3 | 3 | 3 | 3 | 3 |

Сингулярны только **чередующиеся** раскладки (LRLR/RLRL) — то есть сама X-логика.
Управляемая альтернатива для радиальных осей — **все 4 колеса одной руки (напр. LLLL)**:
ранг 3, оси роликов по диагоналям 45/135/225/315°, один режим проскальзывания
(ω₁ − ω₂ + ω₃ − ω₄ = 0). Но это **4 одинаковых колеса, а не 2L+2R**, и эффективные
направления тяги — диагональные. Прочие ранг-3 раскладки (напр. LLRR) тоже управляемы,
но не имеют стандартной интерпретации.

### 1.3. Альтернатива (задача 2) — схема P: стандартная X кинематика подтверждена

Колёса FL/FR/RL/RR на диагоналях (+u,+u), (+u,−u), (−u,+u), (−u,−u), оси **параллельны (‖ Y)**,
X-ориентация роликов: FL+RR = L, FR+RL = R. Строка матрицы: `[1, −h, −(y + h·x)]`, ПЧ = `r·ω_i`:

```
M = [ 1  −1  −2u ]  FL(L)        ранг = 3  ✓ полное управление Vx, Vy, ωz
    [ 1   1   2u ]  FR(R)
    [ 1   1  −2u ]  RL(R)        режим проскальзывания (единственный, общий для 4-колёсных):
    [ 1  −1   2u ]  RR(L)        ω_FL + ω_RR = ω_FR + ω_RL
```

Свип 16 раскладок: схема P сингулярна при LLLL/RRRR/RLLR (одна рука или соседние пары),
**стандартная X-раскладка (LRRL) — ранг 3**. Обратная кинематика — стандартная форма
(`stage2g_v5_kinematics.json`).

**Вывод по задачам 1–2:** правильная кинематика Mecanum достигается либо (P) параллельными
осями со стандартной X-раскладкой, либо (R) радиальными осями с нестандартной раскладкой
«все одной руки». Раскладка v4 (X на радиальных осях) непригодна.

## 2. Задача 3 — сравнение схем

| Критерий | R — радиальные оси | P — параллельные ‖Y на диагоналях |
|---|---|---|
| Кинематика | X-раскладка СИНГУЛЯРНА (ранг 2); управляема только «всё одной руки» (ранг 3, нестандарт) | стандартная X, ранг 3 ✓ |
| Опора колёс, Ø640/D152 | **A = 0.162 м², инрадиус 201 мм** | A = 0.115 м², инрадиус 151 мм (−25 %) |
| Зона лифта Ø240 | ниши не доходят: запас +28…+49 мм | внутренние углы колёс заходят в зону: **−34…−115 мм** |
| Полоса привода (belt) | 28–49 мм | 0–38 мм |
| Секторы АКБ | ±30…±55 мм | ±50…±75 мм |
| Аутригеры | на 45° (между колёсами) | на 0/90/180/270° (между колёсами) |
| Колёса | 4 одинаковых (одной руки) | 2L + 2R (стандартный комплект) |
| Мин. диаметр D152 | **hub 603 / belt 661** | hub 708 / belt 664 |

Геометрическая причина отставания P: колесо на диагонали с параллельной осью вытянуто и по X,
и по Y от центра — внутренний угол проекции `(u−D/2, u−W/2)` уходит к центру гораздо сильнее,
чем радиальная ниша схемы R.

## 5. Задача 8 — опорные контуры и предварительная устойчивость

Контур = выпуклая оболочка пятен контакта. Угол опрокидывания `α = atan(инрадиус / h_ЦМ)`
для ЦМ в центре — **геометрия, без масс** (пример: Ø640, D152):

| Состояние | Схема | A, м² | Инрадиус, мм | α при h=300 / 500 / 700 / 900 |
|---|---|---|---|---|
| Транспорт (колёса) | R | 0.162 | 201 | 33.8 / 21.9 / 16.0 / 12.6° |
| Транспорт (колёса) | P | 0.115 | 151 | 26.7 / 16.8 / 12.1 / 9.5° |
| Рабочее (ход 300) | обе | 0.583 | 382 | 51.8 / 37.4 / 28.6 / 23.0° |

Ходы аутригеров (параметры): 200 мм → A = 0.35–0.41 м²; 300 → 0.54–0.58; 400 → 0.77–0.82.

**Чего не хватает для полноценного расчёта (обязательный список):**
1. Подтверждённая масса робота (300–450 кг — не подтверждены) и массы подсистем.
2. Координаты ЦМ (x, y, z) в транспортном и рабочем состояниях, включая выдвинутые руки/лифт.
3. Нагрузки манипуляторов/лифта: масса груза, вылет, ударные коэффициенты.
4. Динамика: разгон/торможение, повороты, экстренная остановка.
5. Коэффициент трения линолеум/каучук (и с учётом влажности), допустимое точечное давление.
6. Распределение нагрузок по колёсам (статически неопределимая схема) и жёсткость подвески.

## 6. Задача 6 — приводы: «hub=OK» НЕ подтверждён

- Поиск (SearXNG, открытые источники): колёса Mecanum продаются комплектами **2L+2R**,
  крепление к мотору — через **отдельные ступицы/адаптеры** (например, ступица под
  60-мм колесо: длина стакана 16 мм и более с каждой стороны). **Интегрированных
  мотор-колёс Mecanum с чертежами в открытых источниках не найдено.**
- Поэтому полоса «hub = 0 внешней полосы» (и ширина `W_hub = W+60`) — **условна**;
  прежние бейджи hub=OK подтверждением существования пригодного мотор-колеса не являются.
- Требуется: чертежи конкретного изделия (колесо + мотор-редуктор + крепёж + кабели),
  проверка фактических ширин `W_asm/W_hub` и теплового режима.
- До тех пор все три полосы (0/60/150) — параметры с допусками ±20–30 мм, и вердикты
  §4 чувствительны к ним: запасы единицы мм (напр. R/600/D152 hub: −1.6 мм).
