## 1. Ошибка знака высоты препятствия и её исправление

**Было (v7.1):** `delta = Q@u − h`, `F = k·delta` → подъём пола (h > 0) **уменьшал**
сжатие пружины — противоречило физическому смыслу h как высоты препятствия.

**Стало (v7.2):** сжатие между телом и точкой пола
`delta_i = C + h_i − tx·x_i − ty·y_i` — подъём пола увеличивает сжатие, подъём
тела уменьшает; в базисе `Q = [1, −x, −y]`: `delta = Q@u + h`; равновесие
`B^T·F = (Mg, Mg·ex, Mg·ey)` с `B = [1, x, y]`.

**Контрольный пример (400 кг, k = 100000 Н/м, бугор +10 мм под колесо 0):**

| | N1 / N2 / N3 / N4, кгс |
|---|---|
| v7.1 (с ошибкой) | 74.5 / 125.5 / 74.5 / 125.5 |
| **v7.2 (исправлено)** | **125.5 / 74.5 / 125.5 / 74.5** |
| ожидание заказчика | 125.5 / 74.5 / 125.5 / 74.5 ✅ совпало |

Физический смысл исправления: препятство под колесом **нагружает своё колесо**
(125.5) и разгружает поперечные (74.5); в v7.1 направление было обратным.
