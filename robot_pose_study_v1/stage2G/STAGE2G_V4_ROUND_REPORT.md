## 4. Размещение колёс и внешний контур (п.3, 4, 5)

- Оси колёс **горизонтальные, радиальные**; колёса стоят на осях 0/90/180/270°;
  ось колеса на предельном радиусе `r_c = √(R²−(D/2)²) − W/2`.
- **Фактический контур проверен по всем вершинам всех тел каждой группы:**
  `max_r = R_панели = R_env` ровно (300/310/320) — колёса касаются окружности,
  ролики/ступицы/блоки аутригеров не выступают. **CHECK PASS 9/9.**
- Транспортное положение аутригеров: угловой блок `R−120..R−20`, полутангенс 80 мм →
  угол `√((R−20)²+80²)` ≤ R ✓ без выступов.
- **Кинематика 2L+2R сохранена:** X-конфигурация (FL+BR = левое, FR+BL = правое) —
  маркеры руки в каждой группе CAD (`hand_FL_L`, `hand_FR_R`, ...).
- Замечание по контуру Ø152: радиальная грань колеса (290–310) внутри кромки панели →
  колесо в закрытом кармане — вопрос обслуживания (съёмный борт/люк) в §9.

## 6. Компоновочное пространство (п.7)

- **Лифт:** центральный цилиндр Ø240 — ниши до него не доходят ни в одной комбинации
  (внутр. граница ниши 154–221 ≥ 130) ✓.
- **4 привода колёс:** полосы 24–91 мм по осям колёс (таблица §5) — объёмы в CAD показаны
  при band>0; при hub приводе полоса нужна только под ступицу/крепёж.
- **Аккумуляторы/электроника:** секторы 45° (между нишами) — полутангенс 30–105 мм,
  но радиальная глубина всего **40–60 мм** (кольцо от зоны лифта до блоков аутригеров):
  объём мал для батарей 300–450-кг робота → **размещение батарей требует отдельного
  объёмного анализа** (под панелью / центральный отсек / вертикальные стойки) — в список исходных данных.
- **Приводы аутригеров:** внутри угловых блоков у борта (параметрический объём 100×160×100).
