## 3. Ограничения для CAD-моделирования

1. Габарит **670 × 670 × 176 мм** — ограничение Blender-модели, **не утверждённая рама**.
2. Сплошной алюминиевый блок 213 кг **не назначается** (габаритный блок ≠ деталь, аудит 2В.1 §1).
3. Масса считается только для деталей с заданными геометрией И материалом; компоновочные объёмы — без массы.
4. Крепление лифта: ось (+0.003, −4.41) мм от центра базы, ход −774.567…+427.315 мм — из Blender; **совместимость с реальными направляющими/винтом не подтверждена** (узлы в модели — прокси).
5. Опорный контур 0.266435 м² — подтверждён; устойчивость **не пересчитывалась** (2В/2В.1 ограничения).
