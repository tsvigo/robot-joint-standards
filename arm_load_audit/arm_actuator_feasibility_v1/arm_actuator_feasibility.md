## 6. Ошибки методики предыдущего аудита и пересмотр T*

**Что было:** T* = max(|τ_A K1|, |τ_C85 K1|) — только момент от нагрузки, K1.

**Что не учтено:**
1. собственный вес дистальных звеньев (SW): j1 от −67.5 до −289.3 Н·м [Р];
2. для j3 — поза вылета: SW 81.6…348.5 Н·м против 3.1…13.3 Н·м в покое [Р];
3. сильная зависимость от хвата (K1→K3t: j3 до +31%, запястье-2 до ×14) — частично [П].

**Пересмотр [Р]:** `T*_нов(сценарий) = |τ_нагрузки|max(K1 по семейству) + |SW|(критическая поза)`.
Оговорка: это **консервативная огибающая** (сумма модулей). В конкретных позах знаки могут вычитаться (например, j1 в покое: огибающая 871.9, фактическая сумма меньше). Эффект второго порядка (влияние новых масс приводов на SW) не итерируется [П, B11].

| Сустав | v1 | new lean / nom / heavy (L) | new lean / nom / heavy (R) |
|---|---|---|---|
| j3 | 853.7 / 877.6 | 936.6 / 1015.2 / 1203.5 | 968.9 / 1053.2 / 1256.8 |
| j1 = j2 | 804.7 / 831.3 | 871.9 / 936.5 / 1093.6 | 903.9 / 973.8 / 1145.4 |
| локоть | 853.7 / 877.6 | 936.6 / 1015.2 / 1203.5 | 968.9 / 1053.2 / 1256.8 |
| лучелоктевой | 20.0 | 20.0 / 20.0 / 20.0 | 20.0 / 20.0 / 20.0 |
| w1 = w2 | 20.0 / 15.4 | 20.6 / 20.8 / 22.3 | 15.9 / 16.1 / 17.5 |

Последствия: тяжёлый сценарий j3 +41%, j1 +36%; запястья при K1 +1…2%. Дополнительные методические замечания v1: классовые допущения j2/локтя/запястий были условными (A08, A10 v1); k·T* — без калибровки; опубликованные итоги v1 округлены (см. §10.2, сноска).

## 9. Архитектуры A–E

Общая рамка [Р]: **ни одна из архитектур A–E не уменьшает сам момент от груза, передаваемый через сустав** (груз 100 кг на плече 0.8–1.07 м: j1 lean — 804.4 из 871.9 Н·м, 92%; j3 heavy — 855.0 из 1203.5 Н·м, 71%). Архитектуры влияют на распределение массы/инерции, КПД, люфт, сложность и риски. Компенсация силы тяжести снимает только часть SW, не момент груза (груз — переменная, заранее неизвестен).

### A. Прямой привод: двигатель + редуктор на суставе
- **Уменьшает подвижную массу:** ничего (весь узел в дистальном звене).
- **Добавляет:** полную массу узла в каждое последующее звено → каскадное усиление моментов проксимальных суставов; на каждом суставе — тормоз.
- **КПД/люфт/жёсткость/инерция:** КПД волнового редуктора ~70–80% [П]; люфт ~0 (harmonic) [П]; жёсткость высокая [О]; инерция ротора с редуктором отражается ×i² — значимая [О].
- **Риски отказа:** потеря питания → падение груза без тормоза (критично, B16); перегрев при длительном удержании.
- **Данные для сравнения:** масса и габарит узла, момент/скорость, тепловой режим, момент тормоза.

### B. Двигатель с высокопередаточным редуктором
- Отличие от A: i = 100–160:1 → требуемый момент двигателя меньше (~12.5–14.3 Н·м при 120:1; ~9.4–10.7 при 160:1 [Р при η [П]]), но выходная скорость падает (2500/160 ≈ 15.6 об/мин для CSF-50 [Р]); ограничение — входная скорость редуктора из каталога [Ф].
- Масса двигателя снижается, отражённая инерция растёт, КПД одноступенчатого не падает линейно [О].
- Риски: нехватка выходной скорости; те же риски удержания/тормоза.

### C. Удалённый двигатель с ременной/зубчатой/иной передачей
- **Уменьшает подвижную массу:** двигатель (+тормоз) переносится в проксимальную часть/основание — на j3/j1 это снимает ~8–15 кг [О] с дистали и её инерцию.
- **Добавляет:** шкивы, ремни/зубчатые колёса, натяжители, защиту; часть — на подвижной части; натяжение ремня создаёт постоянные радиальные нагрузки на опоры [О].
- **КПД/люфт/жёсткость/инерция:** КПД ремня ~95–98% [П]; люфт и упругость ↑ (точность ↓) [О]; жёсткость ↓; инерция шкивов добавляется.
- **Риски отказа:** обрыв/проскальзывание ремня → потеря управления грузом; износ.
- **Данные для сравнения:** передаваемый момент, ширина/тип ремня, длины, натяжение, КПД, люфт — отсутствуют, сравнение количественно невозможно.

### D. Механическая компенсация силы тяжести (пружина/газ. пружина/противовес)
- **Уменьшает:** постоянный гравитационный момент **руки** (SW: j1 67–289, j3 82–349 Н·м [Р]) — но не момент груза (804–855 Н·м [Р]).
- **Добавляет:** пружины/механизмы, крепления, упоры; для противовеса — десятки кг на плече противовеса [О]; всё это входит в SW и инерцию (не бесплатно).
- **КПД/люфт/жёсткость/инерция:** пассивный элемент; добавляет люфт и нелинейность усилия по углу [О]; рабочий диапазон ограничен.
- **Риски отказа:** отказ пружины → скачок нагрузки на привод (груз удерживает привод; падение возможно при отсутствии тормоза).
- **Данные для сравнения:** момент компенсации vs угол, масса/габарит механизма, диапазон, влияние на инерцию.

### E. Комбинированная (компенсация + привод)
- Компенсация снимает 6–28% момента проксимальных суставов в рассмотренных позах [Р: j1 67.5/1093.6≈6%, j3 348.5/1203.5≈29%] — груз (доминирующая часть) остаётся на приводе.
- Добавляет массу механизма компенсации, её крепления и инерцию; количественный эффект требует выбора механизма [Н].
- Все риски A/B/C + риск отказа компенсатора (см. D).

**Победитель не назначается** (по заданию): для количественного сравнения нужны единые данные по массам узлов, КПД, люфту, диапазонам и скоростям — их нет. Качественный итог: A/B — база; C — снижает дистальную массу/инерцию ценой люфта и сложности; D/E — не решают проблему момента от груза.

## 12. Неизвестные и параметры следующего этапа

1. Скорости и траектории: ω по суставам, ускорения, время цикла, режим (удержание/движение) — без них нет продолжительного/пикового/мощностного требования.

5. Компоновка: где драйверы, кабели, крепёж, датчики; что переносится в основание (архитектуры C/D/E).
6. Пальцы: приводы, механика, точность.
7. Рабочая зона/диапазоны суставов (ограничить огибающую вместо семейства 0–90°).
8. Распределение нагрузки L/R и сценарий асимметрии (60/140 рассчитан как чувствительность).
