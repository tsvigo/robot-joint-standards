# AGENTS.md — проект «робот»

Работа с `.blend` — только через Blender MCP открытой сессии
(см. глобальный `~/.config/opencode/AGENTS.md`: секции про blender-guard,
проверку доступности MCP и Git-резервирование — они действуют и здесь).

## Сохранение .blend (обязательно)

Правки живут в памяти открытой сессии, пока не вызван save:

1. Атомарно в одном `execute_blender_code`: мутация → `view_layer.update()` → `bpy.ops.wm.save_mainfile()` → вернуть новые значения.
2. Проверка следа на диске: `git status` (`M`?), размер/mtime изменились, возвращённые значения сошлись.
3. Только после этого — Git backup-commit результата. Коммит до проверки запрещён.
4. Не пакетировать «10 правок — один save». Headless-правки запрещены (blender-guard).
5. Файл `*.blend1` (авторезерв Blender) не удалять без явного согласия пользователя.

## Git

Перед изменением файлов — проверка по глобальной секции Git-резервирования.
`.blend` — бинарник: каждый коммит хранит его целиком, коммитить осознанно.
