# Human Joint Specification Standard
# Стандарт именования анатомических суставов человека
# Target: Blender -> URDF -> USD -> NVIDIA Isaac Sim
## General rule
Every human anatomical joint MUST have a globally unique name.
Joint name format:
<side>_<body_region>_<segment>_<joint_type>_joint
or shortened form:
<side>_<segment>_<joint_type>_joint
The name MUST uniquely identify:
- body side
- anatomical region
- specific bone connection
- joint type
- digit number (for fingers/toes)
Do NOT use ambiguous names:
- shoulder_joint
- elbow_joint
- wrist_joint
- finger_joint
- interphalangeal_joint
because they can represent multiple anatomical structures.
--------------------------------------------------
# Side convention
Allowed values:
left
right
center
Examples:
left_hip_coxofemoral_joint
right_knee_tibiofemoral_joint
center_atlas_axis_joint
--------------------------------------------------
# Anatomical naming rules
## Spine
Format:
center_spine_<region>_<level>_joint
Examples:
center_spine_cervical_C1_C2_joint
center_spine_thoracic_T1_T2_joint
center_spine_lumbar_L1_L2_joint
--------------------------------------------------
# Shoulder complex
The shoulder is NOT a single joint.
Use:
right_sternoclavicular_joint
right_acromioclavicular_joint
right_glenohumeral_joint
Do not use:
right_shoulder_joint
--------------------------------------------------
# Elbow and forearm
Required names:
right_humeroulnar_joint
right_humeroradial_joint
right_proximal_radioulnar_joint
right_distal_radioulnar_joint
--------------------------------------------------
# Wrist
Use anatomical names:
right_radiocarpal_joint
right_midcarpal_joint
Avoid:
right_wrist_joint
--------------------------------------------------
# Hand and fingers
## Finger numbering
Use anatomical digit numbering:
digit1 = thumb
digit2 = index finger
digit3 = middle finger
digit4 = ring finger
digit5 = little finger
## Thumb joints
Examples:
right_digit1_carpometacarpal_joint
right_digit1_metacarpophalangeal_joint
right_digit1_interphalangeal_joint
Alternative readable aliases:
right_thumb_CMC_joint
right_thumb_MCP_joint
right_thumb_IP_joint
Both names must map to the same internal identifier.
## Fingers 2-5
Every finger MUST specify:
digit number + joint type
Example index finger:
right_digit2_MCP_joint
right_digit2_PIP_joint
right_digit2_DIP_joint
Meaning:
MCP:
metacarpophalangeal joint
PIP:
proximal_interphalangeal joint
DIP:
distal_interphalangeal joint
Full example:
right_digit3_MCP_joint
right_digit3_PIP_joint
right_digit3_DIP_joint
--------------------------------------------------
# Hip
Use:
right_coxofemoral_joint
or:
right_hip_coxofemoral_joint
Avoid:
right_leg_joint
--------------------------------------------------
# Knee
The knee contains several articulations.
Use:
right_tibiofemoral_joint
right_patellofemoral_joint
Avoid:
right_knee_joint
--------------------------------------------------
# Ankle and foot
Use:
right_talocrural_joint
right_subtalar_joint
right_toe1_metatarsophalangeal_joint
right_toe1_interphalangeal_joint
Toe numbering:
toe1 = big toe
toe2 = second toe
toe3 = third toe
toe4 = fourth toe
toe5 = little toe
--------------------------------------------------
# Joint metadata specification
Every joint object SHOULD contain metadata:
joint:
name: right_digit2_PIP_joint
parent_link:
right_digit2_proximal_phalanx
child_link:
right_digit2_middle_phalanx
anatomical:
side: right
digit: 2
region: hand
type: proximal_interphalangeal
simulation:
type: revolute
axis:
x: 1
y: 0
z: 0
limits:
lower: 0
upper: 110
--------------------------------------------------
# Blender / Isaac Sim requirements
Joint names MUST:
- be unique in the entire model
- be stable after export
- not depend on Blender object numbering
- preserve anatomical meaning after URDF/USD conversion
Preferred naming:
right_digit2_PIP_joint
not:
Bone.034
or:
joint_034
--------------------------------------------------
# Robotics mapping
Human anatomical joint -> robot articulation:
revolute:
hinge-like movement
example:
finger PIP/DIP
elbow
knee
spherical:
multi-axis movement
example:
shoulder
hip
fixed:
fused anatomical structures
The anatomical name is the source of truth.
The simulation joint type is a separate property.
